# MRP: Breaking and Defending Convolutional Neural Networks

## Overview
This repository contains the code and presentation for a Mini Research Problem (MRP) exploring the vulnerability of Convolutional Neural Networks (CNNs) to white-box adversarial attacks, alongside an empirical evaluation of different defense mechanisms. 

The project evaluates standard CNNs trained on the MNIST dataset against mathematically crafted perturbations designed to force misclassification.

## Repository Contents
* `at-mrp.py`: The core Python script containing the model architecture, training loops, attack generation algorithms, and evaluation metrics.
* `Breaking_and_Defending_CNNs.pdf`: The 10-minute slide deck presentation summarizing the motivation, literature review, methodology, and results.
* `adversarial_evidence.png`: Visual output generated by the script demonstrating the imperceptible nature of the perturbations.

## Methodology
1. **White-Box Attacks Evaluated:**
   * **FGSM** (Fast Gradient Sign Method): A fast, single-step gradient attack.
   * **PGD** (Projected Gradient Descent): A powerful, iterative version of FGSM constrained within an $l_\infty$ norm ball.
2. **Defenses Evaluated:**
   * **Easy Defense (Gaussian Blurring):** A pre-processing denoising step intended to disrupt high-frequency adversarial noise prior to classification.
   * **Adversarial Training:** Training the network natively on a continuous stream of adversarial examples to fundamentally shift decision boundaries.
3. **Models Evaluated:**
   * **Standard Baseline Model:** Trained purely on clean data.
   * **FGSM-Trained Model:** Trained with single-step adversarial examples.
   * **PGD-Trained Model:** Trained with strong, iterative adversarial examples.
