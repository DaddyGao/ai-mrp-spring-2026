# MRP: Breaking and Defending Convolutional Neural Networks

## Overview
This repository contains the code and presentation for a Mini Research Problem (MRP) exploring the vulnerability of Convolutional Neural Networks (CNNs) to white-box adversarial attacks, as well as the effectiveness of different defense mechanisms. 

The project evaluates standard Convolutional Neural Networks trained on the MNIST dataset against mathematically crafted perturbations designed to force misclassification.

## Repository Contents
* `mnist_aa_experiments.py`: The core Python script containing the model architecture, training loops, attack generation algorithms, and defense evaluations.
* `Breaking_and_Defending_CNNs.pdf`: The 10-minute slide deck presentation summarizing the motivation, literature review, methodology, and results.
* `adversarial_evidence.png`: Visual output generated by the script demonstrating the imperceptible nature of the perturbations.

## Methodology
1. **Baseline Model:** A custom CNN trained to high accuracy (~99%) on the MNIST grayscale dataset.
2. **White-Box Attacks Evaluated:**
   * **FGSM** (Fast Gradient Sign Method): A fast, single-step gradient attack.
   * **PGD** (Projected Gradient Descent): A powerful, iterative version of FGSM constrained within an $l_\infty$ norm ball.
   * **MI-FGSM** (Momentum Iterative FGSM): An iterative attack utilizing momentum to bypass local maxima.
3. **Defenses Evaluated:**
   * **Easy Defense (Gaussian Blurring):** A pre-processing denoising step intended to disrupt high-frequency adversarial noise.
   * **Realistic Defense (Adversarial Training):** Training the network natively on a continuous stream of FGSM-generated adversarial examples to fundamentally shift decision boundaries.
